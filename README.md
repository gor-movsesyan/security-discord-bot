# Bodyguard

Bot Discord orienté sécurité et surveillance de serveur.

## Security Monitoring

Bodyguard surveille les arrivées de nouveaux membres sur le serveur.

Lorsqu'un membre rejoint le serveur, le bot détecte l'événement `on_member_join` et envoie automatiquement un message dans le canal `🔐 security-logs`.

Cette fonctionnalité constitue la première brique du système de Security Monitoring.

## Fonctionnalités actuelles

- Commande `!ping`
- Détection des nouveaux membres
- Journalisation des arrivées dans `🔐 security-logs`
